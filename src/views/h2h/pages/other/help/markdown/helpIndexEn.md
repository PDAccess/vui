## <a name= "services"></a>Services

---

Under the services header you can check all kinds of services that conditioned on PDAccess. There is a green button that you see on the right side of the screen that is "Create New Services" under that button admin can fix and make new services

| Service Topics       | Description                                                                                                                                                                                                   |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|                      |                                                                                                                                                                                                               |
| **Create Service**   | There is a green button that you see on the right side of the screen that is "Create Service" under that button admin can fix and make new services.                                                          |
| **Your Service**     | The page where you can see the services you have.                                                                                                                                                             |
| **Marked Service**   | The services you mark appear here. If you want to mark a service, simply enter the service and press the mark button.                                                                                         |
| **Activities**       | In Activities header Admin can check all the "Sessions, Actions, Live Sessions and Online Users". It represents whole activities just pointed on two main things that are mostly "When" and "What" questions. |
| **Local Account**    |                                                                                                                                                                                                               |
| **Members**          | The part where users registered to the service are listed and we add a new user to the service                                                                                                                |
| **Policy**           | The page where we add restrictions to the services and see the added restrictions.                                                                                                                            |
| **Alarm**            | The page that sends email to the administrator when the restricted command is typed and we can manage the restricted commands.                                                                                |
| **Agent Policy**     |                                                                                                                                                                                                               |
| **Maintenance**      | The page where people who can access the service during maintenance are managed.                                                                                                                              |

## <a name= "groups"></a>Groups

---

Under the Groups header, Admin can see both "Your Groups" and "Explore Groups", "Your Groups" describes the groups that admin already involved. Thus, "Explore Groups" describes the groups that admin does not get involved in. There is a green button that you see on the right side of the screen that is "Create New Groups" under that button admin can set the new groups if you need it.

| Group Topics       | Description                                                                                                                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|                    |                                                                                                                                                                                             |
| **Create Group**   | On the group page, there is a green button that you can see on the right side of the screen, under this button there is "Create New Group", which the admin can fix and create a new group. |
| **Your Group**     | The page where you can see the groups you have.                                                                                                                                             |
| **Explore Groups** | Explore the groups you can use.                                                                                                                                                             |
| **Activities**     | Track the actions of group users.                                                                                                                                                           |
| **Users**          | See the list of users in the group and add new users.                                                                                                                                       |
| **Policy**         | Add custom restrictions to group members. List the restrictions that are registered.                                                                                                        |
| **Alarm**          | The page that sends email to the administrator when the restricted command is typed and we can manage the restricted commands.                                                              |
| **Agent Policy**   | Bilmiyorum                                                                                                                                                                                  |
| **Group Settings** | Edit your group settings.                                                                                                                                                                   |

## <a name= "activities"></a>Activities

---

In Activities header Admin can check all the "Sessions, Actions, Live Sessions and Online Users". It represents whole activities just pointed on two main things that are mostly "When" and "What" questions.

| Activities Topics   | Description                                                                                                                                          |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
|                     |                                                                                                                                                      |
| **Live Sessions**   | You can see the duration time and also when the action started by a user.                                                                            |
| **Sessions**        | You can select users, services and date range hence, controlling the user's sessions is getting easy in one line.                                    |
| **Actions**         | You can check the situations that are going on in your company what users do? For instance, with this controlling logged in or logged out so simple. |
| **Authentications** | We can see the device information of the users and when they are logged in.                                                                          |
| **Vault Logs**      | Shows the break the glass made in the system.                                                                                                        |
