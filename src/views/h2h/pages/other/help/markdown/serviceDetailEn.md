## Service Settings

___

<img src="../helpImage/serviceSettings.png" alt="Mark Service" width="800"/>

<br>You can change the settings of the service.

**Service Host & Port Settings:** You can update service host and port but we will not see current host and port data, if you want see this data use must Break The Glass.  
<br>**Service Edit:** You can make updates about your service by changing the name and description of the specified service.  
<br>**Service Delete:** You can delete the service by entering the first 3 characters of the service name.  
<br>**Service Video Record:**  
<br>**Service Maximum Session & Idle Timeout:** You can update service session maximum time and idle timeout.  
<br>**Service Credential Type:** You can change the service credential.
- **Transparent:** In Transparent mode PDAccess will use users login credentials
- **Vault:** In Vault mode PDAccess will store credentials and allows to change it.
- **Auto:** In Auto mode PDAccess will manage credentials itself(recomended).
