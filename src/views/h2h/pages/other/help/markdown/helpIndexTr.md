## <a name= "services"></a>Servisler

---

Servis başlığı altında PDAccess'e bağlı bütün servisleri kontrol edebilirsiniz.

| Servis Başlıkları    | Açıklama                                                                                                                                                                                                      |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|                      |                                                                                                                                                                                                               |
| **Servis Oluştur**   | Ekranın sağ üst tarafında gördüğünüz yeşil bir buton var ve butonun ismi Crate Service. Admin yetkisi ile servis oluşturabilirsiniz.                                                                          |
| **Your Service**     | Bağlantılı olduğunuz servisleri buradan görebilirsiniz.                                                                                                                                                       |
| **Marked Service**   | İşaretlenmiş servisleriniz burada listelenir. Bir servisi işaretlemek isterseniz işaretlemek istediğiniz servisin içine giriniz ve mark service butonuna basınız.                                             |
| **Activities**       | In Activities header Admin can check all the "Sessions, Actions, Live Sessions and Online Users". It represents whole activities just pointed on two main things that are mostly "When" and "What" questions. |
| **Local Account**    |                                                                                                                                                                                                               |
| **Members**          | The part where users registered to the service are listed and we add a new user to the service                                                                                                                |
| **Policy**           | The page where we add restrictions to the services and see the added restrictions.                                                                                                                            |
| **Alarm**            | The page that sends email to the administrator when the restricted command is typed and we can manage the restricted commands.                                                                                |
| **Agent Policy**     |                                                                                                                                                                                                               |
| **Maintenance**      | The page where people who can access the service during maintenance are managed.                                                                                                                              |
| **Service Settings** | Edit your service settings.                                                                                                                                                                                   |
